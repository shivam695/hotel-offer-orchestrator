Hotel Offer Orchestrator

Node.js (TypeScript) · Express · Temporal · Redis · Docker Compose

View source code Read the README

What it does

Fetches hotel offers from two mock suppliers in parallel using a Temporal workflow, removes duplicates by hotel name, keeps the cheapest offer for each hotel, and saves the result in Redis so it can be filtered by price range.

How it works

  1. GET /api/hotels?city=delhi starts a Temporal workflow.
  2. The workflow calls Supplier A and Supplier B in parallel, with automatic retries.
  3. Hotels are de-duplicated by name and the cheaper offer wins.
  4. The final list is stored in a Redis sorted set where the score is the price.
  5. With minPrice and maxPrice, the filtering runs inside Redis (ZRANGEBYSCORE).
  6. If one supplier is down, the workflow continues with the other one.

Endpoints

EndpointPurpose
GET /api/hotels?city=delhiBest offer per hotel
GET /api/hotels?city=delhi&minPrice=5000&maxPrice=6000Price filter inside Redis
GET /healthHealth of both suppliers and Redis
GET /supplierA/hotels, /supplierB/hotelsMock suppliers

Run it yourself

git clone https://github.com/shivam695/hotel-offer-orchestrator.git
cd hotel-offer-orchestrator
docker compose up --build

Then open http://localhost:3000. The Temporal dashboard is at http://localhost:8233.

Testing

A Postman collection is included in the postman/ folder: 12 requests and 22 automated tests covering overlapping offers, price filters, a city with no results, invalid input, health checks and a supplier outage. All 22 tests pass.
